# 渐进式披露 (Progressive Disclosure) 架构与重构规范

## 3 层架构 (L1 / L2 / L3)

- **L1 元数据层 (Metadata)**:
  - Agent 初始加载或工具列表中的工具名称与单行简述（~50-100 token）。
  - 职责：告知系统何时触发该技能，不加载具体正文。
- **L2 骨架层 (SKILL.md 正文)**:
  - 核心职责、规模预判分流表（S/M/L）、阶段状态机、完成与退出准则。
  - 控制在 100~150 行以内，不含任何特定语言模板、大段测试用例或分支专有提示词。
- **L3 资源层 (references/)**:
  - 条件性依赖文件：模板代码、规范细则、失败案例反思表（Tabu list）。
  - 当且仅当进入特定分支或需要该信息时，由 Agent 按需 `read_file`。

## 效果收益

- 即使项目中配置 10+ 个专业技能，每个会话初始加载仅 1000~2000 token，相比单体式大提示词减少约 90% 常驻上下文开销。
