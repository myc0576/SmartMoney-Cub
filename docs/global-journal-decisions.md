# 全球复盘：调研依据与实现决策

安全边界：`READ_ONLY_NO_ORDER_NO_CANCEL_NO_TRADE`。本产品记录与分析用户自己的交易，不执行订单，不修改券商账户，不提供买卖建议。

## 从交割记录到可解释模式

Tradervue 使用标签描述交易场景，并支持按标签比较不同交易集合、从分组报告下钻到具体交易。这适合把“我可能擅长某类交易”的模糊判断变成可核对的分组问题，而不是替用户猜测动机。[官方交易分析介绍](https://www.tradervue.com/site/trading-analysis)、[标签报告](https://app.tradervue.com/help/reports_tags)。

Edgewonk 的产品介绍将入场、出场、交易管理和风险决策分别分析。可借鉴的是拆分问题的维度；商业宣传中的“找到优势”不应直接成为本产品的结论保证。[官方产品介绍](https://edgewonk.com/stock-trading-journal)。以上网站于 2026-09-23 查阅。

本项目采用以下可审计步骤：

1. 先规范化成交身份、账户、合约、方向、数量、费用、币种、时间精度和来源；缺失字段保留未知。
2. 按账户、合约和计价单位配对成交，重建持仓回合。部分成交不等于主动加仓，成交记录不等于交易意图。
3. 分轴描述：持仓周期（日内、短隔夜、波段、长持仓）、入场形态（顺势、突破、均值回归候选）、建仓行为（单次/多次成交）。趋势与日内可以同时成立，不设计成互斥的人格分类。
4. 交割记录可支持持仓时间等事实；入场形态必须有可验证的入场前行情及可得时间。只有日期时，不推断分钟级超短线；没有行情时，不把盈利自动解释成趋势交易。
5. 每个候选提供原始成交链接、观察值、缺失数据、算法版本与失效条件。确认、否决、重命名和关联交易计划保存在用户账本中，不自动晋级交易规则。
6. 画像中的样本门槛和主导占比是描述性筛选规则，不是统计显著性或盈利概率。历史正收益不是稳定优势；需要时间外验证、费用完整性、市场状态分层和足够样本才能讨论稳定性。

## 回放保留，但必须承担实际任务

回放分为真实成交复盘和独立模拟训练。前者将已记录成交叠加到历史行情；后者逐根揭示行情，模拟指令按下一根开盘处理，不污染真实账本。会话持久化，回退创建独立分支，未来行情和未来成交标记不能提前返回给浏览器。

历史行情的抓取时间不等于历史可得时间。未经验证的行情仍可用于图表复盘，但必须显示限制，不能宣称满足严格的时点回测证据要求。模拟结果也不代表真实成交质量、滑点或可执行收益。

## 全球连接的实际覆盖边界

“面向全球”指数据模型不假设 A 股规则、整股数量或人民币，不等于已经支持世界上所有券商。

| 通道 | 用户提供/操作 | 限制 |
|---|---|---|
| Binance / OKX，经 CCXT | 自有只读 API 凭据、账户别名和明确交易对 | 校验权限；历史窗口依服务商而异，必要时补充交割文件 |
| IBKR Flex | 自有 Flex token、XML 查询 ID | 报表可能异步生成；查询必须包含所需成交字段 |
| MetaTrader | 用户自行登录的只读终端 | 不自动登录；验证已连接且交易权限关闭，API 无法证明实际密码类型 |
| 本地目录 / rotki 导出 | 用户选定 CSV/JSON 目录 | 自动导入需明确开启，程序运行时生效；不是自动操作券商导出 |
| SnapTrade Personal MCP | 官方 OAuth 授权 | 可选联网通道；本地回调模式，真实账户覆盖取决于服务商 |
| Vezgo | 用户自己的开发者凭据 | 可选商业服务；本产品不代办付费订阅，复杂兑换需人工映射 |

来源：[CCXT](https://github.com/ccxt/ccxt)、[IBKR Flex](https://www.interactivebrokers.com/docs/web-api/api-reference/get-statement)、[MetaTrader 授权说明](https://www.metatrader5.com/en/terminal/help/startworking/authorization)、[SnapTrade MCP](https://docs.snaptrade.com/docs/mcp-server)、[Vezgo API](https://vezgo.com/docs/api/)、[rotki 导入说明](https://docs.rotki.com/usage-guides/history/import-data.html)。

插件密钥入口必须对应真正需要密钥的服务商，而不是简单链接插件仓库。外部项目自行管理的密钥不应交给本地安装器收集。vn.py 不进入官方插件市场；移除展示不涉及删除用户外部安装的项目。

## 验证声明

自动化测试使用离线虚构交易、协议形状一致的服务商响应和本地服务。协议测试通过不等于某个真实券商账户已经连接成功。真实授权、服务商费用、地区可用性与账户历史完整性需要用户在自己的服务商环境确认。不得用这些外部限制掩盖本地功能或验收尚未完成。
