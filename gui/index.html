这是开发入口，不是工作台

这个文件只供构建工具使用。直接用浏览器打开它会得到空白页，因为它引用的是 尚未编译的 /src/main.tsx，本地服务也没有在运行。

请先启动本地工作台，再打开它打印的地址：

python -m smartmoney_cub_harness.cli workbench
# 或
npx smartmoney-cub

之后访问 http://127.0.0.1:8787。界面默认只监听本机回环地址。

开发时需要热更新，请在 gui/ 目录执行 npm install && npm run dev，它会把 /api 代理到本地服务。
